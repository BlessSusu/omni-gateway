## 1. 协议概要

GB/T 28181 视频监控联网使用 **SIP（RFC 3261）** 作信令，媒体为 RTP/PS。网关首期仅处理 **TCP 信令**：

- `REGISTER`：设备注册 → 鉴权绑定 `DeviceID`
- `MESSAGE` / `NOTIFY`：携带 `Application/MANSCDP+xml` 或 `Application/MANSCDP+xml` 国标 XML
- 下行（M19）：`MESSAGE` + `DeviceControl` / `INVITE` 等

## 2. 嗅探与定界

| 项 | 规则 |
|----|------|
| detect | 前缀匹配 `REGISTER `、`MESSAGE `、`NOTIFY `、`INVITE `、`SIP/2.0` |
| 帧界 | Header 以 `\r\n\r\n` 结束；Body 长度由 `Content-Length` 决定 |
| 端口 | 建议 **5060** 独立监听，避免与 JT808 二进制嗅探冲突 |

## 3. 设备 ID

从 `From` / `Contact` / XML `<DeviceID>` 提取 20 位编码，作为 `session.deviceId`。

## 4. 上行物模型

| CmdType（XML） | messageType | 说明 |
|----------------|-------------|------|
| Register | register | 注册（可与 SIP REGISTER 并存） |
| Keepalive | keepalive | 心跳 |
| Catalog | catalog | 目录 |
| Alarm | alarm | 报警 |
| 其他 | 原样 CmdType | payload 含 `xml`、`headers` |

## 5. 鉴权响应

`REGISTER` 成功 → `SIP/2.0 200 OK`（含 Via/From/To/Call-ID/CSeq）。

## 6. 下行（M19 规划）

| commandType | 行为 |
|-------------|------|
| DeviceControl | MESSAGE + Broadcast/Record 等 XML |
| InviteStream | INVITE + SDP（推流地址由业务 payload 提供） |
