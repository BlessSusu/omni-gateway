## 1. 协议概要

GB/T 28181 视频监控联网使用 **SIP（RFC 3261）** 作信令，媒体为 RTP/PS。网关首期处理 **TCP 信令**：

| 信令 | 网关行为 |
|------|----------|
| `REGISTER` | 鉴权绑定 20 位 `DeviceID` → `200 OK` |
| `MESSAGE` / `NOTIFY` | MANSCDP+xml → Thing Model → Kafka |
| 下行 `MESSAGE` / `INVITE` | 由 `Gb28181DownlinkBuilder` 编码 |

## 2. 嗅探与定界

| 项 | 规则 |
|----|------|
| detect | 前缀：`REGISTER `、`MESSAGE `、`NOTIFY `、`INVITE `、`SIP/2.0` |
| 帧界 | Header `\r\n\r\n` + `Content-Length` |
| 端口 | **5060** 独立监听（与 JT808 / simple-frame 分离） |

```yaml
omni.gateway.listeners:
  - port: 5060
    plugins: [gb28181]
    sniff:
      max-bytes: 4096
      timeout-ms: 8000
      min-probe-length: 7
```

## 3. 设备 ID

从 `From` / `Contact` / XML `<DeviceID>` 提取 20 位国标编码，作为 `session.deviceId`。

## 4. 上行物模型

| CmdType（XML） | messageType | 说明 |
|----------------|-------------|------|
| Register | register | 注册 |
| Keepalive | keepalive | 心跳 |
| Catalog | catalog | 目录 |
| Alarm | alarm | 报警 |
| 其他 | 原样 CmdType | payload 含 `xml`、`headers` |

## 5. 鉴权响应

`REGISTER` 成功 → `SIP/2.0 200 OK`（Via/From/To/Call-ID/CSeq）。

## 6. 下行（M19）

| commandType | 行为 |
|-------------|------|
| `InviteStream` / `INVITE` | SIP INVITE + SDP（`streamUrl`、`mediaPort`） |
| `DeviceControl` / `Broadcast` | MESSAGE + MANSCDP Control |
| `Catalog` | MESSAGE + Catalog Query |
| 自定义 | `payload.xml` 原样下发 |

实现类：`Gb28181Plugin.encodeDownlink` → `Gb28181DownlinkBuilder`。

## 7. 联调建议

1. 设备或模拟器连 `host:5060`，发 `REGISTER`。
2. 查 `omni_connections_active`、`Device authenticated` 日志。
3. 下行发至 `omni.command.downlink.{nodeId}`，`protocol` 填 `gb28181`。
4. Redis 开启时可用 `GET /api/v1/devices/{deviceId}/route` 查 nodeId。
